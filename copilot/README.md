# Copilot sandbox environment

Run the copilot-cli in a sandboxed environment so that it has limited access to the system.

 - `docker compose run --build copilot`

# Restore sessions

Follow the tutorial in: https://docs.github.com/en/copilot/concepts/agents/copilot-cli/chronicle#reindexing-the-session-store

Basically just run: `/chronicle reindex`
